白桃スパークリングティー 新商品告知バナー

制作区分
自主制作
制作概要
夏季限定の「白桃スパークリングティー」の発売を告知するための広告バナー。
制作目的
新商品の認知拡大と、白桃の瑞々しさや炭酸の爽快感を視覚的に伝えることで、購買意欲を高めること。
ターゲット
20〜30代の女性。フルーツティーや季節限定ドリンクに関心があり、見た目の華やかさや爽やかさを重視する方。
デザインの意図

淡いピンクやピーチカラーを基調に、白桃の甘さと夏らしい爽やかさを表現しました。

グラスを斜めに大きく配置し、周囲に桃や氷、炭酸の泡を散りばめることで、動きのある華やかなビジュアルに仕上げています。

また、グラスの水滴や弾ける泡を強調することで、冷たさや炭酸の爽快感が直感的に伝わるよう工夫しました。

商品名や価格は画面下部にまとめ、発売日を大きく配置することで、商品の魅力と販売情報の両方が伝わる構成を意識しました。

使用ツール
Adobe Illustrator / Adobe Photoshop

白桃ミルクパンケーキ｜季節限定メニュー告知バナー

制作区分

制作物

制作概要

「悩み → 解決 → 特徴 → お客様の声 → 購入」という流れで構成し、自然と下へ読み進められるようにしました。

宿ブランド「NAGI（凪）」公式サイト

制作区分
自主制作（架空の宿ブランド）
制作概要
全国に6つの宿をもつ宿ブランド「NAGI（凪）」の公式サイト。トップ、コンセプト、宿の一覧と詳細（6施設）、お知らせ、ご利用案内、予約フォームなど全18ページ。
制作目的
自然の中で何もしない時間を過ごせる宿の魅力を伝え、予約につなげること。
ターゲット
日常から離れて自分を整えたい20〜30代の男女（ひとり旅・カップル・友人同士）。
担当範囲
要件定義、サイト設計、デザイン、コーディング、公開
デザインの意図

「心が凪ぐ場所へ」というコンセプトから、余白を多くとり、大きな写真と明朝体、落ち着いたアースカラーで静けさを表現しました。

トップは霧の夜明けの湖から始まり、6つの宿の写真へゆっくり切り替わります。

コーディング

PC・スマホ対応（スマホファースト）。予約フォームは「入力 → 確認 → 完了」の画面の切り替えと入力チェックをJavaScriptで再現しました。

写真をWebPにして画面の幅に合った大きさを読み込むなど、表示の速さにも気を配りました。

WordPress
練習として、このサイトをWordPressのオリジナルテーマにする作業も行いました（ローカル環境）。
使用ツール
HTML / CSS / JavaScript / WordPress
