人材育成サービス「NEXLEAD」ランディングページ

制作区分
スクール課題
制作概要
管理職研修や次世代リーダー育成を行う企業向けサービス「NEXLEAD」のランディングページ。
制作目的
人材育成に悩む企業の担当者に、研修だけでなく育成の「仕組み」から伴走するサービスだと伝え、無料相談や資料ダウンロードにつなげること。
担当範囲
ワイヤーフレーム、デザイン、コーディング
デザインの意図

信頼感のあるネイビーとブルーを基調にしました。相談ボタンにはイエローを使い、ページの中で目に留まりやすくしています。

「お悩み → 原因 → 特徴 → 選ばれる理由 → 研修プログラム → 導入事例 → 流れ → よくある質問」の順に構成し、読み進めるうちに相談したくなる流れにしました。

コーディング
PC・スマホ対応（レスポンシブ）。ハンバーガーメニューと、導入事例を左右に送れるスライダーをJavaScriptで実装しました。
使用ツール
Figma / HTML / CSS / JavaScript
