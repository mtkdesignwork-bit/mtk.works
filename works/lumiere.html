美容液「LUMIÈRE SERUM」ランディングページ

制作区分
スクール課題
制作概要
忙しく働く女性に向けた、濃密美容液「LUMIÈRE SERUM」の販売を想定したランディングページ。
制作目的
初回限定セット（1,000円）で気軽に試してもらうことを入口に、定期便の購入につなげること。
ターゲット
20代後半〜30代前半の働く女性。仕事の忙しさからスキンケアが後回しになりがちで、乾燥やくすみが気になり始めている方。
担当範囲
リサーチ、ペルソナ設定、ワイヤーフレーム、デザイン、コーディング
デザインの意図

白をベースに、ベージュとネイビーを組み合わせて清潔感と上品さを表現しました。見出しには明朝体を使い、美容液らしい落ち着いた高級感を演出しています。

「悩み → 解決 → 特徴 → お客様の声 → 購入」という流れで構成し、自然と下へ読み進められるようにしました。

コーディング
PC・スマホ対応（レスポンシブ）。
使用ツール
Figma / HTML / CSS / JavaScript
